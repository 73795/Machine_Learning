## Lab 1 — Baseline Models and System Cost

This laboratory uses the Breast Cancer Wisconsin dataset to train and evaluate two machine learning models.

Models:
- Logistic Regression
- Random Forest

The project includes model accuracy, training time, inference latency, model size, memory measurements, and a laboratory report.

## Project Structure

- `Lab1ML/src/` — Python source code
- `Lab1ML/results/` — results and saved models
- `Lab1ML/report.md` — laboratory report
- `requirements.txt` — Python dependencies
- `.gitignore` — excluded files
